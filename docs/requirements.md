# 瞬間英作文ツール 要件定義書（v0.4）

作成日: 2026-11-24 / 更新日: 2026-11-25
ステータス: 承認済み（2026-11-25）。M1・M2・M2.5・C1 実装済み

> v0.4（2026-11-27）：Claude の使用量を使ってよいことになり、claude.ai の非公開ページを「英作文コーチ」（自分の書きたい文を添削する形）に変更。問題集（240問）は GitHub Pages 版に残す。詳細は 10章。

> v0.3（2026-11-25）：「簡単すぎる」とのフィードバックを受け、ビジネス英文を主役に変更。文法は独立したステージにせず、ビジネス文の中に混ぜて身につける方針にした。

---

## 1. 目的

- 日本語の文を見て、すぐ英語の文を作る力（瞬間英作文）を鍛える。
- **ビジネスでよく使う英文**（長め・複文）を瞬時に書けるようにする。
- 文法は独立して学ぶのではなく、ビジネス文の中に混ぜ、使っていくうちに理解できるようにする。
- 使うのは本人1人だけ。ログイン機能や他人向けの配慮は要らない。

## 2. 決まっていること（ヒアリング結果）

| 項目 | 決定内容 |
|---|---|
| 利用環境 | Windows PC と Android スマホ（どちらもブラウザで使う Web アプリ） |
| 置き場所 | GitHub Pages（無料） |
| 回答方法 | タイピングで英文を入力し、正解と比べる |
| 問題の用意 | 最初にまとめて作成してアプリに入れる。あとから自分で追加もできる |
| レベル構成 | ビジネス場面が主役。1文15〜25語程度の長め・複文が中心。文法は各問題にタグと解説で付け、混ぜて学ぶ（v0.3 で変更） |
| ヒント | 日本文の下に「使う表現」を表示する（設定で非表示にできる） |
| 回答時間 | 記録するだけ。判定や復習には使わない |
| 学習記録の引き継ぎ | 不要。PC とスマホで別々に記録する |
| 1日の量 | 約15分（新しい問題10問＋復習） |
| 英語の種類 | アメリカ英語 |
| 重点のビジネス場面 | メール・チャット / 会議・オンライン会議 / 交渉・提案・プレゼン |

## 3. 学習の流れ（1問の流れ）

1. 日本語の文が表示される。
2. 英文をタイピングして、Enter（スマホは「判定」ボタン）で送信。
3. 判定結果を表示する。
   - **正解**: 緑で表示。
   - **惜しい**: 違う部分を色分けして表示（例: 冠詞の抜け、スペルミス）。
   - **不正解**: 正解の英文を表示。
4. 正解の英文を音声で読み上げる（ブラウザの読み上げ機能を使う。無料）。
5. 判定が厳しすぎたときは「これも正解」ボタンで自分の答えを正解扱いにでき、その答えを別解として登録する。
6. 次の問題へ。

## 4. 機能要件

### 4.1 必須（最初のバージョンに入れる）

| ID | 機能 | 内容 |
|---|---|---|
| F-01 | 出題 | 選んだユニット（複数可）から日本文を出題する。複数選ぶと混ぜて出題。順番通り／ランダム、1回の問題数（10／20／すべて）を選べる |
| F-01b | ヒント | 日本文の下に、使う表現（例：I would appreciate it if you could 〜）を表示する。表示の ON/OFF を切り替えられる |
| F-01c | 文法タグ | 判定後に、その文で使っている文法（仮定法・分詞構文など）をタグで表示し、解説を添える |
| F-02 | タイピング回答 | 英文を入力して判定する |
| F-03 | 判定のゆるさ | 大文字小文字、句読点、余分なスペースは無視する。短縮形（I'm = I am など）、数字（five = 5）、％（15% = 15 percent）、時刻（3pm = 3 p.m.）、OK = okay、e-mail = email は同じとみなす。please はあってもなくても正解。1つの問題に複数の正解（別解）を持てる |
| F-04 | 差分表示 | 自分の答えと正解の違う単語を色分けして見せる |
| F-05 | 自己判定の上書き | 「これも正解」で正解扱いにし、別解として保存する |
| F-06 | 読み上げ | 正解の英文をアメリカ英語の声で読み上げる。速度を変えられる |
| F-07 | 回答時間の記録 | 1問ごとの回答時間を記録し、結果画面に平均を出す。判定や復習には使わない |
| F-08 | 習熟度の記録 | 問題ごとに、正解数・不正解数・最後に解いた日を記録する |
| F-09 | 復習（間隔反復） | 間違えた問題を、間隔を空けて再出題する（1日後→3日後→7日後→14日後→30日後）。正解すると間隔が延び、間違えると1日後に戻る |
| F-10 | ユニットのクリア | ユニットの問題の8割に正解したらクリアとする。ロックはせず、どのユニットもいつでも選べる |
| F-11 | 問題の追加 | アプリ上で日本文・英文（別解も）・ユニット・メモを登録、編集、削除できる |
| F-12 | 控えの書き出し／読み込み | ブラウザのデータが消えたときに備え、学習記録と自作問題を JSON ファイルで書き出し、読み込んで戻せる |
| F-13 | 今日の学習 | ホーム画面に「今日の復習○問」「新しい問題○問（初期値10）」と、連続学習日数を表示する |

### 4.2 あとで追加（v2 以降の候補）

- 音声入力での回答（話す練習用）
- 答えを見て自己採点するだけの「口頭モード」（スマホで入力が面倒なとき用）
- AI（Claude API）による問題の自動生成、自分の英文の添削
- 苦手な文法の分析グラフ
- PC とスマホの記録の同期（今回は不要と決定。必要になったら検討）

## 5. 問題の内容

### 5.1 構成（v0.3）

**ビジネス場面**（各場面80問、計240問。1ユニット16問）

| 場面 | ユニット |
|---|---|
| メール・チャット | 依頼する / 確認・問い合わせ / 日程調整 / 報告・進捗共有 / お詫び・トラブル対応 |
| 会議 | 会議の進行 / 意見を述べる・賛成反対 / 質問・確認・聞き返し / まとめ・次のアクション / オンライン会議 |
| 交渉・提案・プレゼン | 提案する / 条件交渉 / 譲歩・断り・クロージング / プレゼン：導入・展開 / プレゼン：データ説明・質疑応答 |

- 各問題に、使っている文法のタグ（仮定法、分詞構文、関係代名詞、間接疑問、使役など）と短い解説を付ける。
- **基礎（中学文法）**：be 動詞の1ユニット（20問）を残す。独立した文法ステージは作らない。
- 今後の追加候補：その他の場面（自己紹介・挨拶 / 電話・接客 / 雑談）、各場面の問題の追加。
- つづり・言い回しはアメリカ英語で統一する。

### 5.2 問題データの形（1問）

```json
{
  "id": "mail-request-002",
  "unit": "依頼する",
  "grammarTags": ["仮定法", "助動詞"],
  "ja": "お手数ですが、添付の契約書をご確認のうえ、今週金曜日までにご返信いただけますか。",
  "hint": "I would appreciate it if you could 〜 and get back to me by 〜",
  "en": ["I would appreciate it if you could review the attached contract and get back to me by this Friday."],
  "alternatives": ["I would appreciate it if you could check the attached contract and get back to me by this Friday."],
  "note": "I would appreciate it if you could 〜 は could を使った仮定法の丁寧表現。",
  "source": "builtin"
}
```

- 最初に用意する問題は `source: "builtin"`、自分で追加した問題は `source: "user"` で区別する。
- 問題の作成は Claude が行い、ユーザーがあとから直せるようにする。

## 10. 英作文コーチ（v0.4 で追加）

### 10.1 決まっていること

| 項目 | 決定内容 |
|---|---|
| 置き場所 | claude.ai の非公開ページ（本人がログインしたときだけ開ける）。https://claude.ai/artifact/U215EKywUtD9yfo1jsQ2w9 |
| Claude の利用 | 本人の claude.ai の使用量で動く（API キー・追加料金なし）。初回に利用の許可を求められる |
| 非公開ページの中身 | 英作文コーチだけにする。問題集は GitHub Pages 版で使う |
| 保存 | 添削した文章は claude.ai 側に保存し、PC とスマホで共有する。本人以外は読めない場所（data/users/本人）に置く |
| 場面・相手 | 任意で選べる。選ばなければ Claude が文面から判断する |

### 10.2 流れ

1. 書きたい文章（日本語）を入力する。場面（社外メール・会議での発言など）と相手（取引先・上司など）は任意で選ぶ。
2. Claude が「英語にしやすい日本語」に言い換える（主語を補う・1文1メッセージ・直訳しにくい表現を具体化など）。言い換えたところを箇条書きで示し、使えそうな英語の型はヒントとして隠しておく。言い換えた日本語は自分で直せる。
   - 言い換えは3段階を1回の依頼でまとめて作り、ボタンで切り替える（2026-11-27 追加）：「1 かんたん」（すごく簡単に言う言い方。中学英語で言える短い文）／「2 言いやすく」（書いた文章の内容はそのままに言いやすくした言い方。最初はこれ）／「3 より良く」（こう言うともっと良くなる言い方）。最後に選んだ段階を記憶する。
   - 添削では、どの段階を見て書いたかを Claude に伝え、その段階の内容を表せているかで評価する。復習ではその段階の言い換えを出題する。
   - 骨組みヒント（「1 かんたん」のときだけ表示）：1文ずつ、英語の語順で「誰が → する → 何を → いつ」などの部品を並べる。最初は英語を隠し、部品を押す／「次を見る」／「全部見る」で見せる。
   - 単語ヒント（3段階とも）：言い換えた日本語の中で英語にしにくい言葉と、簡単な英語の候補（例：延期する → move / push back）。
   - 骨組みと単語ヒントは言い換えと同じ1回の依頼で作る。
   - 骨組みヒントは、簡単な単語のまま場面に合った言い方で作る（そのまま送っても問題ない英文）。「かんたん」で添削するときは見せた骨組みを Claude に伝え、骨組みどおりの表現は正解として直さない・減点しない。復習でも骨組みどおりの英文を正解にする（2026-11-27 修正：骨組みどおりに書いたのに直される問題）。
   - 「1 かんたん」の英語（骨組み・単語ヒント・使えそうな表現、かんたんを見て書いたときの添削の修正版・お手本）は、中学1〜2年で習う基本の単語だけを使う（acquisition などの難しい単語は使わない）。広告の仕事でそのまま使う言葉など、どうしても必要な単語だけは使ってよく、その場合は「※ 注釈」として日本語の意味と使う理由を必ず示す。骨組みでは英語が隠れていても ※ で難しい単語が入る部品が分かるようにする。
   - ①の「例文を入れる」：広告配信会社の業務を想定した例文20個から、ランダムに1つ入れる（場面・相手も設定。直前と同じ例文は避ける）。例文は coach/examples.js。
3. 自分で英文を書く。
4. Claude が添削する。添削結果を保存し、履歴と復習に追加する。何度でも書き直して添削し直せる。

### 10.3 添削で示す内容

| 項目 | 内容 |
|---|---|
| 点数 | 100点満点（正確さ40・自然さ30・丁寧さ／トーン30） |
| 直した英文 | 自分の英文をできるだけ活かした最小限の修正版。直した単語に印を付ける |
| 直すところ | 誤り（文法・語法・意味のずれ・失礼な表現）。元の表現 → 直した表現と、なぜダメか。点数はここだけで減点する |
| もっと良くなるところ | 誤りではないが、より自然・丁寧・簡潔になる言い換え。点数には影響しない |
| 良かったところ | 1〜2個 |
| より自然な言い方 | 2〜3通りと、それぞれのニュアンス |
| 丁寧さ・トーン | 適切／丁寧すぎる／くだけすぎ／失礼になりうる と、その理由 |
| お手本 | 復習で使う英文を1つ |

### 10.4 復習・履歴

- 復習：保存した文章の「英語にしやすい日本語」を出題し、英文をタイピングで答える。判定はお手本・修正版・自然な言い方・90点以上だった自分の英文と照らして端末内で行う（Claude の使用量を使わない）。必要なときだけ「Claude に添削してもらう」で詳しく添削し、90点以上なら正解扱いにする。
- 出題順：まだ復習していない順に10問／ランダムに10問。
- 履歴：保存した文章の一覧（元の文章・言い換え・お手本・自然な言い方・最新の自分の英文と点数・復習の成績）。削除は2回押しで確定。
