# 瞬間英作文ツール 要件定義書（v0.2）

作成日: 2026-11-24 / 更新日: 2026-11-25
ステータス: 承認済み（2026-11-25）。M1・M2 実装済み

---

## 1. 目的

- 日本語の文を見て、すぐ英語の文を作る力（瞬間英作文）を鍛える。
- 最初は中学レベルの文法から始め、最終的には**ビジネスでよく使う英文**を瞬時に書けるようにする。
- 使うのは本人1人だけ。ログイン機能や他人向けの配慮は要らない。

## 2. 決まっていること（ヒアリング結果）

| 項目 | 決定内容 |
|---|---|
| 利用環境 | Windows PC と Android スマホ（どちらもブラウザで使う Web アプリ） |
| 置き場所 | GitHub Pages（無料） |
| 回答方法 | タイピングで英文を入力し、正解と比べる |
| 問題の用意 | 最初にまとめて作成してアプリに入れる。あとから自分で追加もできる |
| レベル構成 | 中学文法 → 高校文法 → ビジネス場面 の順。中学文法は be 動詞から全部やる |
| 回答時間 | 記録するだけ。判定や復習には使わない |
| 学習記録の引き継ぎ | 不要。PC とスマホで別々に記録する |
| 1日の量 | 約15分（新しい問題10問＋復習） |
| 英語の種類 | アメリカ英語 |
| 重点のビジネス場面 | メール・チャット / 会議・オンライン会議 / 交渉・提案・プレゼン |

## 3. 学習の流れ（1問の流れ）

1. 日本語の文が表示される。
2. 英文をタイピングして、Enter（スマホは「判定」ボタン）で送信。
3. 判定結果を表示する。
   - **正解**: 緑で表示。
   - **惜しい**: 違う部分を色分けして表示（例: 冠詞の抜け、スペルミス）。
   - **不正解**: 正解の英文を表示。
4. 正解の英文を音声で読み上げる（ブラウザの読み上げ機能を使う。無料）。
5. 判定が厳しすぎたときは「これも正解」ボタンで自分の答えを正解扱いにでき、その答えを別解として登録する。
6. 次の問題へ。

## 4. 機能要件

### 4.1 必須（最初のバージョンに入れる）

| ID | 機能 | 内容 |
|---|---|---|
| F-01 | 出題 | 選んだユニットから日本文を出題する。順番通り／ランダムを選べる |
| F-02 | タイピング回答 | 英文を入力して判定する |
| F-03 | 判定のゆるさ | 大文字小文字、文末のピリオド、余分なスペースは無視する。短縮形（I'm = I am、don't = do not など）は同じとみなす。1つの問題に複数の正解（別解）を持てる |
| F-04 | 差分表示 | 自分の答えと正解の違う単語を色分けして見せる |
| F-05 | 自己判定の上書き | 「これも正解」で正解扱いにし、別解として保存する |
| F-06 | 読み上げ | 正解の英文をアメリカ英語の声で読み上げる。速度を変えられる |
| F-07 | 回答時間の記録 | 1問ごとの回答時間を記録し、結果画面に平均を出す。判定や復習には使わない |
| F-08 | 習熟度の記録 | 問題ごとに、正解数・不正解数・最後に解いた日を記録する |
| F-09 | 復習（間隔反復） | 間違えた問題を、間隔を空けて再出題する（1日後→3日後→7日後→14日後→30日後）。正解すると間隔が延び、間違えると1日後に戻る |
| F-10 | ユニットのクリア | ユニットの問題の8割に正解したらクリアとする。ロックはせず、どのユニットもいつでも選べる |
| F-11 | 問題の追加 | アプリ上で日本文・英文（別解も）・ユニット・メモを登録、編集、削除できる |
| F-12 | 控えの書き出し／読み込み | ブラウザのデータが消えたときに備え、学習記録と自作問題を JSON ファイルで書き出し、読み込んで戻せる |
| F-13 | 今日の学習 | ホーム画面に「今日の復習○問」「新しい問題○問（初期値10）」と、連続学習日数を表示する |

### 4.2 あとで追加（v2 以降の候補）

- 音声入力での回答（話す練習用）
- 答えを見て自己採点するだけの「口頭モード」（スマホで入力が面倒なとき用）
- AI（Claude API）による問題の自動生成、自分の英文の添削
- 苦手な文法の分析グラフ
- PC とスマホの記録の同期（今回は不要と決定。必要になったら検討）

## 5. 問題の内容

### 5.1 構成

**ステージ1: 中学文法**（各ユニット15〜20文、計約300文）
be 動詞 / 一般動詞の現在形 / 過去形 / 進行形 / 未来（will, be going to） / 助動詞（can, must, should, may） / 疑問詞 / 比較 / 不定詞 / 動名詞 / 受動態 / 現在完了 / 関係代名詞 / 接続詞（when, if, because）

**ステージ2: 高校文法**（計約200文）
仮定法 / 分詞構文 / 間接疑問 / 使役（have, let, make, get） / 関係副詞 / 強調・倒置の基本形

**ステージ3: ビジネス場面**（計約300文）

| 場面 | 文数の目安 | 内容 |
|---|---|---|
| メール・チャット ★重点 | 約90 | 書き出し・結び / 依頼 / 確認 / お礼 / 日程調整 / 報告・進捗 / 謝罪 |
| 会議・オンライン会議 ★重点 | 約80 | 開始・進行 / 意見を言う / 賛成・反対 / 質問・聞き返し / まとめ・次のアクション / 接続トラブル |
| 交渉・提案・プレゼン ★重点 | 約80 | 提案する / 条件の交渉 / 譲歩・断り / プレゼンの導入・展開・締め / 質疑応答 |
| その他 | 約50 | 自己紹介・挨拶 / 電話・接客 / 雑談 |

- ステージ3でも、どの文法を使っているかタグを付け、ステージ1・2とつなげる。
- つづり・言い回しはアメリカ英語で統一する。

### 5.2 問題データの形（1問）

```json
{
  "id": "biz-mail-012",
  "stage": 3,
  "unit": "メール：依頼",
  "grammarTags": ["助動詞", "不定詞"],
  "ja": "添付の資料をご確認いただけますか。",
  "en": ["Could you please check the attached document?"],
  "alternatives": ["Could you check the attached file?", "Would you please review the attached document?"],
  "note": "Could you〜? は Can you〜? より丁寧。",
  "source": "builtin"
}
```

- 最初に用意する問題は `source: "builtin"`、自分で追加した問題は `source: "user"` で区別する。
- 問題の作成は Claude が行い、ユーザーがあとから直せるようにする。

## 6. 画面

| 画面 | 内容 |
|---|---|
| ホーム | 今日の復習数・新しい問題数、連続学習日数、「始める」ボタン |
| ユニット一覧 | ステージ別のユニット一覧と、それぞれの習熟度（クリア済み、正答率） |
| 出題 | 日本文、入力欄、判定結果、正解、読み上げボタン、解説メモ |
| 結果 | そのセッションの正答率、平均回答時間、間違えた問題の一覧 |
| 問題の管理 | 自作問題の追加・編集・削除、検索 |
| 設定 | 1日の新しい問題数、出題順、読み上げ速度、控えの書き出し／読み込み |

## 7. 非機能要件

| 項目 | 内容 |
|---|---|
| 対応端末 | Windows PC の Chrome / Edge、Android の Chrome |
| 画面 | スマホ幅でも横スクロールなしで使える。入力欄は自動大文字・自動修正を OFF にする |
| 速さ | 判定から次の問題まで待ち時間を感じない（すべて端末内で処理） |
| オフライン | 一度開けば電波がなくても使える（ホーム画面に追加できるアプリ形式＝PWA にする） |
| データ保存 | 学習記録と自作問題は各端末のブラウザ内に保存する。PC とスマホで共有はしない |
| 費用 | 0円（GitHub Pages は無料。サーバー代・API 利用料なし） |
| 公開範囲 | GitHub Pages の URL を知っていれば誰でも開ける。ただし学習記録・自作問題は端末内にあるので他人には見えない。最初から入っている問題データは公開されても困らない内容にする |
| 公開先 | https://takakikikuchi-source.github.io/shunkan-eisakubun/ |

## 8. 作る順番

| 段階 | 内容 | 確認ポイント |
|---|---|---|
| M1 | 出題 → 入力 → 判定 → 差分表示 → 読み上げ。問題は1ユニット（be 動詞）だけ。PC で動かす | PC で実際に解いてみて、判定のゆるさ・操作感を確認 |
| M2 | GitHub Pages に公開、PWA 化 | Android で開いて、入力と読み上げを確認 |
| M3 | ステージ1の全問題、習熟度の記録、復習、ホーム画面、結果画面 | 1週間使ってみて、復習の出方を確認 |
| M4 | ステージ2・3の問題（重点場面から）、問題の追加・編集、控えの書き出し／読み込み | ビジネス文の内容を確認・修正 |
