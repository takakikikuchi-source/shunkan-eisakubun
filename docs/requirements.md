## 1. 目的と前提

| 項目 | 内容 |
|---|---|
| 目的 | 仕事で書きたい日本語を、すぐに英文にできるようになる。最終的にはビジネスでよく使う英文を瞬時に書ける・言えるようにする |
| 使う人 | 本人1人だけ。英語は初心者。広告配信会社で働いている |
| 今の課題 | ①英語は「誰が→する」から組み立てる、という発想に慣れていない　②使う単語がすぐに出てこない |
| 1日の使い方 | 「新しい文を書く」と「復習」をおよそ半々。1日の目標（ノルマ）は画面に出さない |
| 英語の種類 | アメリカ英語 |

## 4. 機能要件

### 4.1 書く（自分の文を言い換え・添削）

| ID | 機能 | 内容 | 状態 |
|---|---|---|---|
| W-01 | 書きたい文章 | 日本語で入力する。場面（社外メール・会議での発言など7種）と相手（取引先・上司など5種）は任意で選ぶ。選ばなければ Claude が文面から判断する | 済 |
| W-02 | 例文を入れる | 広告配信会社の業務を想定した例文から、ランダムに1つ入れる（場面・相手も設定。直前と同じ例文は避ける）。**例文は20個 → 50個程度に増やす**（10章） | 変更 |
| W-03 | 言い換え（3段階） | 1回の依頼で3段階を作り、ボタンで切り替える。最初は**前回選んだ段階**を表示する<br>・1 かんたん：すごく簡単に言う言い方（中学英語で言える短い文）<br>・2 言いやすく：書いた内容はそのままに言いやすくした言い方<br>・3 より良く：こう言うともっと良くなる言い方 | 済 |
| W-04 | 言い換えの編集 | 表示された日本語は自分で直せる。直しは段階ごとに残る | 済 |
| W-05 | 骨組みヒント | 「1 かんたん」のときだけ表示。英語の語順で「誰が → する → 何を → いつ」などの部品を並べ、最初は英語を隠す。部品を押す／「次を見る」／「全部見る」で見せる。簡単な単語で、場面に合った（そのまま送っても問題ない）英文にする | 済 |
| W-06 | 単語ヒント | 3段階とも。英語にしにくい言葉と、簡単な英語の候補（例：延期する → move / push back） | 済 |
| W-07 | 使えそうな表現 | 3段階とも。その段階で使えそうな英語の型（例：Could you 〜?） | 済 |
| W-08 | 言い換えたところ | どこをどう言い換えたかの説明 | 済 |
| W-09 | かんたんの単語制限 | 「1 かんたん」の英語は中学1〜2年の基本の単語だけ。どうしても必要な単語（業界用語など）だけは使ってよく、**※注釈**（日本語の意味と使う理由）を必ず付ける。骨組みでは英語が隠れていても※で分かるようにする | 済 |
| W-10 | 自分の英文 | 英文を書いて「添削する」（PC は Ctrl+Enter でも可） | 済 |
| W-11 | 添削 | 5章の内容を表示する。何度でも書き直して添削し直せる | 済 |
| W-12 | 自動保存 | 添削するたびに保存し、履歴と復習に入れる（8章） | 済 |

### 4.3 復習（間隔反復）

| ID | 機能 | 内容 | 状態 |
|---|---|---|---|
| R-01 | 対象 | ①「書く」で添削した文　②問題集で間違えた問題　を**1つの復習にまとめる** | 変更 |
| R-02 | 出題する文 | **その日に復習する時期が来た文だけ**を出す。タブに件数を表示する（例：復習 5） | 変更 |
| R-03 | 間隔 | 正解するたびに間隔を延ばす：**1日後 → 3日後 → 7日後 → 14日後 → 30日後**。30日後でも正解したら、**以降は30日ごとに出し続ける**（卒業させない）<br>・不正解：翌日に戻す（間隔も1日からやり直し）<br>・**惜しい：間隔を延ばさず、同じ間隔でもう一度出す** | 新規 |
| R-04 | 出題の形 | 「書く」の文：添削したときに見ていた段階の言い換えを出す<br>問題集の問題：問題集と同じ日本文（ヒントは問題集の設定に従う） | 変更 |
| R-05 | 判定 | 端末の中で判定する（使用量を使わない）<br>「書く」の文：お手本・修正版・自然な言い方・90点以上だった自分の英文・骨組みどおりの英文を正解にする<br>問題集の問題：正解・別解・**自分で「これも正解」に登録した別解**を正解にする | 済＋変更 |
| R-06 | Claude に添削してもらう | 「書く」の文だけ、必要なときに押して詳しく添削する。90点以上なら正解扱い | 済 |
| R-07 | 1回の問題数 | 時期が来た文から、1回10問ずつ出す | 変更 |
| R-08 | 廃止 | 「まだ復習していない順に10問」「ランダムに10問」のボタン | 廃止 |

## 5. 添削で示す内容

| 項目 | 内容 | 状態 |
|---|---|---|
| 点数 | 100点満点（正確さ40・自然さ30・丁寧さ／トーン30）。減点するのは「直すところ」だけ | 済 |
| 直した英文 | 自分の英文をできるだけ活かし、誤りだけ直した版。直した単語に印 | 済 |
| 直すところ | 誤り（文法・語法・意味のずれ・失礼な表現）。元の表現 → 直した表現と、なぜダメか | 済 |
| 正解だけど、もっと良くなる言い方 | 書いた表現は正解（骨組みヒントどおりの表現も含む）。書いた表現に「○」。より自然・丁寧・簡潔になる言い換え。点数には影響しない | 済 |
| より自然な言い方 | 2〜3通りと、それぞれのニュアンス | 済 |
| 丁寧さ・トーン | 適切／丁寧すぎる／くだけすぎ／失礼になりうる と、その理由 | 済 |
| お手本 | 復習で使う英文を1つ | 済 |
| 良かったところ | 1〜2個 | 済 |
| ※注釈 | 「かんたん」を見て書いたとき、直した英文・お手本に必要な難しい単語が入ったら注釈を付ける | 済 |
| 見せたヒントの扱い | 「かんたん」で添削するときは、見せた骨組みを Claude に伝え、骨組みどおりの表現は誤りにしない | 済 |

## 10. 例文（W-02）の増やし方

広告配信会社の業務を想定し、次の10場面×5個＝**50個**にする（今の20個は、該当する場面に振り分けて残す）。

| 場面 | 例 |
|---|---|
| 入稿・素材のやりとり | 入稿データの依頼、バナーの差し替え |
| 配信の開始・停止・設定変更 | 配信開始日の確認、配信の一時停止 |
| レポート・数値の報告 | 月次レポートの送付、数値の改善・悪化の説明 |
| 予算・請求 | 予算の消化ペース、請求金額の説明 |
| 計測・タグ・技術的な不具合 | タグの設置確認、表示されない不具合 |
| 審査・広告ポリシー | 審査落ちの連絡、表現の修正依頼 |
| 提案・商談 | 新しいフォーマットの提案、デモの案内 |
| 社内の連絡 | 引き継ぎ、ミーティングの時間変更 |
| 会議での発言 | A/Bテストの結果共有、改善案の提案 |
| お詫び・トラブル対応 | 配信ミスのお詫び、再発防止の説明 |

## 13. やらないこと（今回の範囲外）

- 苦手な文法の分析グラフ
- 電波のない場所での利用
